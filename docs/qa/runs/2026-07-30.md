## Tooling limitation

A formal Core Web Vitals trace requires Chrome DevTools performance tools that are not configured in this task. The run therefore uses build output, route timing, browser console inspection, responsive rendering, reduced-motion inspection, and manual interaction checks. This does not block functional QA.
